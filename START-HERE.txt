┌──────────────────────────────────────────────────────────────────────┐
│ 1. JUST WANT TO SEE IT RUN?  (Docker)                                │
└──────────────────────────────────────────────────────────────────────┘

    docker compose up -d --build

    → http://localhost:8080              the shop
    → http://localhost:8080/admin/login/ admin panel
      mobile 09120000000   password ChangeMe_Admin123

    First boot takes a few minutes: it builds the frontend, imports the
    database schema and loads 17 demo products. Watch it with:

        docker compose logs -f app

    Full guide: docs/DOCKER.md


┌──────────────────────────────────────────────────────────────────────┐
│ 2. DEPLOYING TO YOUR DIRECTADMIN HOSTING?  (the real target)         │
└──────────────────────────────────────────────────────────────────────┘

    Docker is NOT needed and NOT used in production.

    Open  README-DEPLOYMENT.md  and follow the 22 numbered steps.
    Short version:

      a) phpMyAdmin → create a database → import database/schema.sql
         then database/seed.sql
      b) copy config/config.example.php to config/config.php and fill in
         your database name, user, password, and a new app secret
      c) upload the CONTENTS of the release/ folder into public_html/
      d) visit https://yourdomain.com/api/health.php — expect "status":"ok"
      e) create your admin account via /rescue/ and then DELETE /rescue/

    Requirements on the server: Apache with mod_rewrite, PHP 8.0+, MySQL.
    No Node.js. No SSH. No PostgreSQL. No Docker. FTP + phpMyAdmin is enough.

    docs/DOCKER.md           running it in containers

┌──────────────────────────────────────────────────────────────────────┐
│ 4. REBUILDING THE FRONTEND (only if you change the design)           │
└──────────────────────────────────────────────────────────────────────┘

    see the "Local development" section of README.md.
